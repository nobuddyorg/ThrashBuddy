# Contributing to ThrashBuddy

## No outside contributions

ThrashBuddy is a personal hobby project. I don't accept pull requests, issues or feature requests from outside the project; they are closed without review.

Want to change something? **Fork it.** The [MIT License](LICENSE) lets you use, change and redistribute the code in your own fork, no need to ask. There is no support for forks.

To build and run your fork, follow the [Getting Started Guide](docs/getting-started.md).
